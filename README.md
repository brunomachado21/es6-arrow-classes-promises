# Exercícios de ECMAScript 6: Parte 3

Resoluções da atividade prática sobre recursos modernos do JavaScript (ES6).

## Tópicos Abordados
- **Exercícios 1 e 2**: Arrow Functions e Template Strings
- **Exercícios 3 e 4**: Operadores Rest e Spread
- **Exercícios 5 e 6**: Desestruturamento de Objetos (Destructuring)
- **Exercício 7**: Modelagem com Classes e Herança (`extends` e `super`)
- **Exercícios 8, 9 e 10**: Operações Assíncronas com Promises (`resolve`, `reject`, `then` e `catch`)
